Page patterns

A tool page

Every tool is one <section class="tool" id="..."> with the same four parts, in this order.

  1. .tool-head: one h1 and one sentence saying what the tool is for.
  2. .grid or .tool-layout: inputs card on the left, results on the right. Wide tables take the full row.
  3. .card: every block of content. Card titles are small caps h2.
  4. .explain: optional "how it is calculated" below.

Adding a new tool

  1. Copy the section skeleton above into <main> and add its link to the side navigation, under the right heading.
  2. Write initYourTool() and add it to the TOOLS list.
  3. Save inputs with store.get / store.set under a bridgeCalc. key, so the daily Save backup includes it.
  4. Use only tokens from this page. If something is missing, add the token here first, in all three themes.
  5. Check it in Day, Dusk and Night, and on a phone width.
